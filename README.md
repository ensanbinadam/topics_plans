# مخطط توزيع الموضوعات — نسخة المدارس

تطبيق عربي حديث ومستقل لإعداد خطط توزيع الموضوعات الدراسية وإدارتها وطباعتها وتصديرها. يعمل محليًا داخل المتصفح ويحفظ الخطط على جهاز المستخدم، وهو مبني باستخدام React وVite.

## أبرز المزايا

- إنشاء خطة التوزيع تلقائيًا من تاريخ البداية والنهاية، مع عرض التاريخين الهجري والميلادي.
- واجهتان للعرض والطباعة: جدول تفصيلي أو بطاقات أسبوعية.
- مدير متكامل للخطط المحفوظة يتيح الإنشاء والاستنساخ وإعادة التسمية والحذف والتنقل الفوري بين الخطط، مع زر لإفراغ المدير كاملًا بعد التأكيد.
- حفظ تلقائي محلي، مع التراجع وإعادة الإجراء ودعم اختصارات لوحة المفاتيح.
- حفظ نطاقات التواريخ كقوالب مخصصة قابلة لإعادة الاستخدام والحذف.
- لصق قائمة كاملة من الموضوعات دفعة واحدة أو إدخالها وتعديلها يدويًا.
- البحث الفوري في الموضوعات، والسحب لإعادة ترتيبها، وإخفاء الأسابيع عند الحاجة.
- ترحيل الموضوعات يومًا إلى الأمام عند الإجازات والتغييرات المفاجئة، أو سحبها إلى الأعلى لسد الفراغات، مع تجاوز الأسابيع والأيام المعطلة تلقائيًا وعدم وضع موضوعات داخلها.
- زر × مستقل بعد سلة الحذف هو المرجع الوحيد لتعيين أي يوم كإجازة أو إلغاء ذلك، مع حفظ الحالة داخل الخطة وملف JSON؛ ولا يعتبر نص الموضوع أو لون التظليل اليوم إجازة دون تفعيل الزر.
- تظليل الموضوعات بخمسة ألوان للتصنيف، مع خيار مستقل لتلوين نص الموضوع بالأحمر.
- وضع مظلم متجاوب ومحفوظ محليًا.
- اختيار خط النصوص من عدة خطوط عربية، مع ثبات أحجام النصوص في العرض والطباعة والتصدير.
- خطوط Google عربية مستضافة محليًا داخل `assets/fonts`: Cairo وTajawal وAlmarai وNoto Kufi Arabic، مع ملفات تراخيص OFL والعمل دون اتصال.
- تطبيق الأرقام الهندية اختياريًا على الواجهة والجداول والبطاقات والطباعة وجميع صيغ التصدير.

## إدارة الأرشيف وملفات JSON

- تصدير الخطة الحالية إلى ملف JSON للاحتفاظ بنسخة أرشيفية قابلة للتحرير لاحقًا.
- استيراد ملفات JSON القديمة والحديثة وإضافتها تلقائيًا إلى مدير الخطط.
- اختيار عدة ملفات JSON واستيرادها دفعة واحدة بدل فتح كل ملف بصورة منفردة.
- بقاء الخطة الحالية مفتوحة أثناء الاستيراد، لتظهر الملفات الجديدة داخل المدير ويمكن التنقل بينها عند الحاجة.
- حفظ الخطط في IndexedDB ذي السعة الأكبر، لتبقى بعد تحديث الصفحة أو إغلاق المتصفح، وعدم إعلان نجاح الاستيراد قبل اكتمال الحفظ الدائم.
- تجاوز الملف غير الصالح دون تعطيل استيراد بقية الملفات، مع إظهار عدد الملفات الناجحة وغير الصالحة.
- معالجة الأسماء المتكررة تلقائيًا بإضافة `(2)` ثم `(3)` وهكذا، دون الكتابة فوق أي خطة محفوظة.

## الطباعة والتصدير

- طباعة العرض الحالي أو حفظه مباشرة بصيغة PDF.
- طباعة أو حفظ PDF بطريقتين مستقلتين: البطاقات الأسبوعية أو الجدول التفصيلي.
- تخطيط بطاقات A4 أفقي ثابت: 12 بطاقة في الصفحة، موزعة على 4 أعمدة × 3 صفوف.
- توزيع نصوص الموضوعات رأسيًا داخل البطاقة وتكبير الخط تلقائيًا بحسب المساحة المتاحة.
- تصدير Word مطابق لطريقة العرض المختارة: جدول حقيقي أو بطاقات أسبوعية بتخطيط 4×3 متوافق مع Microsoft Word.
- عدم إنشاء صفوف بطاقات فارغة في الصفحة الأخيرة من ملف Word.
- تصدير صفحة HTML مستقلة وتفاعلية تحتوي على إعدادات الترويسة والشعار وبيانات المعلم، مع إمكانية تبديل العرض والطباعة إلى PDF.
- تصدير CSV عربي متوافق مع Excel، ونسخ الجدول للصقه مباشرة في Excel أو Google Sheets.
- تحييد الصيغ المحتملة في النصوص المستوردة عند تصدير CSV للمحافظة على سلامة الملف.
- تصدير نص الموضوعات وملف JSON للأرشفة والاستعادة.
- إخفاء تذييل التطوير من صفحات الطباعة مع بقائه ظاهرًا في واجهة التطبيق.

> ملاحظة: تصدير Excel بصيغة CSV مخصص للبيانات الجدولية، أما الحفاظ على شكل البطاقات أو الجدول كما يظهر في التطبيق فيتوفر في Word وHTML والطباعة وPDF.

## تشغيل المشروع للتطوير

يتطلب المشروع Node.js وnpm، ثم تُنفذ الأوامر من داخل مجلد `plan_s`:

```powershell
npm install
npm run dev
```

## الاختبارات وبناء نسخة الإنتاج

```powershell
npm test
npm run build
```

ينتج البناء داخل مجلد `dist`. بعد كل تعديل برمجي يجب تشغيل الاختبارات ثم إعادة البناء قبل رفع النسخة إلى الموقع.

## ملفات النشر على الموقع

لرفع نسخة المدارس أو تحديثها، تُنقل العناصر التالية مع المحافظة على بنيتها:

- `plan_s.html`
- `index.html` عند استخدامه صفحة الدخول الرئيسية.
- `favicon.ico`
- مجلد `assets` كاملًا، بما فيه ملفات JavaScript وCSS ومجلد `assets/fonts`.

لا تُرفع مجلدات `source` و`node_modules` وملفات الاختبارات إلى خادم الموقع؛ فهي مخصصة للتطوير فقط.

## بنية مجلد نسخة المدارس

```text
plan_s/
├── assets/          # ملفات الإنتاج والخطوط المحلية
├── source/          # الشفرة المصدرية والاختبارات وإعدادات Vite
├── index.html       # صفحة الإنتاج الرئيسية
├── plan_s.html      # صفحة نسخة المدارس
├── favicon.ico
├── package.json
└── package-lock.json
```

## الخصوصية

يعمل التطبيق محليًا في المتصفح، وتُحفظ الخطط في IndexedDB والإعدادات في مساحة التخزين المحلية على جهاز المستخدم. لذلك يُنصح بتصدير الخطط المهمة دوريًا إلى ملفات JSON وحفظ نسخة احتياطية منها.
