# مخطط توزيع الموضوعات — نسخة المدارس

نسخة حديثة ومستقلة لإعداد خطط توزيع الموضوعات الدراسية، مبنية باستخدام React وVite.

## التشغيل للتطوير

```powershell
npm install
npm run dev
```

## الاختبارات والبناء

```powershell
npm test
npm run build
```

ينتج البناء داخل مجلد `dist`. صفحة الإنتاج المنشورة في هذا المجلد هي `plan_s.html`.

## أهم الوظائف

- إنشاء الجدول من نطاق تاريخي مع التاريخين الهجري والميلادي.
- الحفظ التلقائي محليًا والتراجع وإعادة الإجراء.
- التظليل الأصفر وتلوين نص الموضوع بالأحمر.
- تطبيق الأرقام الهندية اختياريًا على جميع النصوص والتواريخ والأرقام في الواجهة والبطاقات والجداول والطباعة وكل صيغ التصدير.
- اختيار خط النصوص من خمسة خيارات نظامية آمنة، مع بقاء الخط الحالي افتراضيًا وثبات جميع أحجام الخطوط في العرض والطباعة والتصدير.
- خطوط Google عربية مستضافة محليًا داخل `assets/fonts`: Cairo وTajawal وAlmarai وNoto Kufi Arabic، مع ملفات تراخيص OFL وتشغيل دون اتصال.
- عرض جدولي أو بطاقات أسبوعية وإخفاء الأسابيع.
- استيراد وتصدير JSON وتصدير النص وWord وHTML تفاعلي مستقل.
- يحترم تصدير Word طريقة العرض المختارة: جدول حقيقي أو بطاقات أسبوعية بتخطيط 4×3 متوافق مع Microsoft Word.
- طباعة أو حفظ PDF بطريقتين مستقلتين: بطاقات أسبوعية أو جدول تفصيلي.
- تخطيط البطاقات ثابت على A4 أفقي: 12 بطاقة في الصفحة (4 أعمدة × 3 صفوف)، مع توزيع الموضوعات رأسيًا وتكبير الخط تلقائيًا بحسب كثافتها.
- يحتوي ملف HTML المُصدّر على إعدادات الترويسة والشعار وبيانات المعلم، ويُظهر التوقيع في الصفحة الأخيرة.
- طباعة محسنة وتخطيط متجاوب مع الجوال، مع إخفاء تذييل التطوير من الطباعة.
